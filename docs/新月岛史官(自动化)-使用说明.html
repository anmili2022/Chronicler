新月岛史官

插件版本：v0.2.0.10+

本地记录新月岛南征/北征 CE 与 FATE 出现时间，支持 xyd 分享码、喊话同步、悬浮窗和自动导航。

Dalamud API 15 Crescent Isle xyd 兼容 vnavmesh Lifestream

主要功能

出现时间记录

自动或手动记录南征、北征 Boss 的出现时间，按本地时间显示为 HH:mm。

xyd 分享码

支持导入和导出 xyd.zzmelon.com 分享码，并生成普通喊话和离岛喊话。

聊天同步

监听游戏聊天中的分享码或史官喊话，自动同步本地记录，不会自动发公频。

悬浮窗

显示当前 FateTable FATE 和 DynamicEventContainer CE，并提供导航、回营地、全自动开关和待命点记录按钮。

全自动导航

可勾选目标列表，目标出现后可延迟自动导航；目标结束后会先回营地，再恢复扫描下一个目标。

调试采集

提供已观测 FATE、CE 动态事件、当前 FateTable、附近 EventObj 等调试数据。

依赖插件

  • vnavmesh：用于自动寻路。
  • Lifestream 2.5.4.15 以上：用于新月岛传送点传送；版本过低或未加载时不会启用传送 IPC。

没有安装依赖时，记录、分享码和聊天同步仍可使用；自动导航相关功能会受限。

安装方法

  1. 在 Dalamud 设置中进入 实验室 或 第三方插件 选项卡。
  2. 添加第三方库链接：
    https://raw.githubusercontent.com/flyrio/TargetSelector/refs/heads/main/TargetSelector.json
  3. 保存后，在 Dalamud 插件管理器中搜索 新月岛史官 或 Chronicler 并安装。

基本使用

  1. 进入新月岛后打开设置窗口：/shiguan 或 /史官。
  2. 确认顶部显示的地图识别为南征或北征。
  3. 需要自动记录时，保持 自动记录出现 开启。
  4. 需要同步别人喊话时，保持 监听聊天同步 开启。
  5. 使用 生成喊话、生成出岛喊话、生成分享码 输出当前记录。
  6. 将分享码或喊话粘贴进共享文本框，点击 应用导入 可同步记录；生成的文本也会写入同一个文本框并自动复制。

主窗口顶部有 南征 / 北征 切换按钮控制当前列表，不受角色所在地图限制，在北岛也可以查看和编辑南岛记录。

主窗口共四个页签：新月岛史官（Boss 列表与导入导出）、自动寻路（全自动导航设置）、设置（通用选项与地图 ID 设置）、DEBUG（调试区与调试数据导出）。

Boss 列表与掉落标记

Boss 表格按地图展示，包含简称、名称、掉落、出现时间和触发条件，可直接点击 记录 / 清除 操作。

  • 南征 CE 的掉落按魂晶颜色标记：红 黄 紫 绿 蓝 碧 金；魔法罐（右上罐/左下罐）标记为 金。
  • 北征 CE 的掉落按类型标记：α β γ。
  • 触发条件已按 xyd 网页数据补齐，例如 Lv.27 新月幽灵(注意位置)、Lv.22 新月永世珍本 等。

宏命令

可以把下面任意一条写进游戏宏：

/shiguan enter
/史官 上岛

前往新月岛入口命令会自动执行：传送到图莱优菈 → 都市传送到幻境村 → 步行导航到新月岛入口。需要已加载 Lifestream 和 vnavmesh。

修改 Boss 出现时间（作用于当前列表对应的地图）：

/shiguan record 鲨鱼
/史官 记录 鲨鱼

把 鲨鱼 的出现时间记录为当前时间。

/shiguan set 鲨鱼 09:30
/史官 设置 鲨鱼 09:30

把 鲨鱼 的出现时间修改为 09:30（格式为 HH:mm）。

/shiguan clear 鲨鱼
/史官 清除 鲨鱼

清除 鲨鱼 的出现时间记录。

简称可在主窗口 Boss 表格第一列查看。

全自动导航设置

  • 全自动模式：开启后自动扫描满足条件的 FATE/CE 并导航。
  • 优先 CE：默认开启；CE 和 FATE 同时满足条件时优先前往 CE。关闭后优先 FATE。
  • 出现后导航延迟：目标出现后等待指定秒数，目标仍存在才导航；默认 5 秒。
  • 结束后回营地延迟：当前目标结束后等待指定秒数再回营地，默认 5 秒。
  • 战斗进度跳过：目标已经开战且进度达到阈值时，不再新出发，默认 80%。
  • 全自动提示：控制 全自动: 和 全自动模式 这类状态消息是否输出到聊天；默认开启。
  • 记录待命点：保存当前坐标和南/北岛信息；回营地完成后可自动前往待命点。再次点击会更新待命点。
  • CE/FATE 全选或全不选：批量控制全自动目标列表。

当前 CE/FATE 结束后，插件会停止当前导航，按延迟回营地，确认读图结束、地图正确、角色已在营地附近稳定后，等待 10 秒再扫描和前往下一个 CE/FATE。

如果 CE/FATE 期间死亡，插件只会停止当前 vnav 导航；复活后不会立即回营地，等当前目标正常结束后再按结束流程回营地。

CE 导航会在 CE 中心 15 码范围内随机选择一个可走坐标，而不是固定导航到圆心。部分目标会使用指定优先传送点，例如暴食咒鬼优先卡纳克城塞。

悬浮窗

  • 显示当前活动 FATE 与 CE。
  • 点击 导航 可手动前往目标。
  • 点击 回营地 会触发亚返回，并自动确认返回弹窗。
  • 如果已记录待命点，手动点击 回营地 后会等待读条和读图完成，再前往待命点。
  • 点击 待命点 可记录或更新当前位置为待命点；鼠标悬停提示为 记录、更新待命点。
  • CE 名称后会按掉落标记显示 [α]、[β]、[γ] 或魂晶颜色，便于识别掉落。
  • 右键悬浮窗可打开或关闭主设置窗口。

DEBUG 页签

主窗口的 DEBUG 页签集中了所有调试功能：

  • 显示调试区：控制下方调试区内容是否显示。
  • 导航调试：输出导航步骤、目标坐标和选中的传送点到聊天。
  • 显示当前位置/CE/FATE距离：列出当前玩家与所有活动 FATE/CE 的距离和坐标。
  • 复制全部调试信息：把基础信息、已观测 FATE、CE 公告、CE 动态事件、当前 FateTable、附近 EventObj 等一次性复制到剪贴板，方便反馈。

开启 显示调试区 后，可以查看：

  • 已观测 FATE：记录所有在当前地图看到过的 FateTable 行。
  • CE 动态事件记录：记录 DynamicEventContainer 中出现过的 CE 数据。
  • FATE/CE 调试区：显示当前 FateTable、传送点检测和附近 EventObj 扫描。

采集到的调试数据会写入插件配置并随游戏保存，可随时用 复制全部调试信息 导出。

注意事项

  • 分享码兼容依赖固定的 17 格 Boss 顺序，不应随意调整主 Boss 列表顺序。
  • 新增北征普通 FATE 只用于 FATE 折叠栏和自动导航，不影响 xyd 分享码。
  • 待命点会记录所属地图；南岛和北岛待命点不会混用。
  • 回营地后前往待命点会至少等待 8 秒，并确认已到营地附近后再启动导航。
  • 全自动只在营地或待命点附近扫描新目标；导航途中地图短暂不可判定时会等待，不会清空当前目标状态。
  • 导航调试关闭时，普通导航步骤不会刷屏；全自动提示关闭时，全自动: 状态消息不会输出；失败和异常仍会提示。
  • 如果传送点或坐标异常，先打开 导航调试 查看目标坐标和选中的传送点。
